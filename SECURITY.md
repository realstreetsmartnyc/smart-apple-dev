# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Email the maintainers at **security@smart-apple-dev.com** (or open a [private security advisory](https://github.com/smart-apple-dev/smart-apple-dev/security/advisories/new)).
3. Include:
   - A description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Any suggested fix (if you have one)

### What to Expect

- **Acknowledgment** within 48 hours.
- **Assessment** within 7 days — we will confirm the issue and determine affected versions.
- **Fix & disclosure** — we will prepare a patch, coordinate a release, and credit you (unless you prefer to remain anonymous).

## Scope

This policy covers the `smart-apple-dev` CLI, its build/signing pipeline, and any first-party GitHub Actions or Docker images we publish. Third-party SDKs, Apple toolchains, and LLM provider APIs are out of scope — please report those to their respective vendors.

## Safe Harbor

We consider security research conducted in accordance with this policy to be authorized. We will not pursue legal action against researchers who follow these guidelines.
